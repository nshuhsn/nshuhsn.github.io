# Seokhyun Lee — personal site

빌드 과정 없는 정적 단일 페이지(`index.html`)입니다.

## GitHub Pages에 올리기
1. GitHub에서 `nshuhsn.github.io` 이름으로 public 레포를 만듭니다.
2. `index.html`을 레포 루트에 올립니다. (사진은 `images/profile.jpg`, CV는 `cv.pdf`로 함께 올리기)
3. Settings → Pages → Branch를 `main` / `root`로 지정하면 몇 분 뒤 `https://nshuhsn.github.io`에서 열립니다.

## 내용 수정
`index.html` 아래쪽 `<script>`의 `NEWS`, `PUBS` 배열만 고치면 됩니다.
- `selected: true` → Selected 탭에 노출
- `first: true` → 학회명이 강조색으로 표시
- 저자 이름 끝의 `*` → 공동 1저자 표시
